# Paradise Nursery 🌿

**Project Name:** Paradise Nursery
**Project Type:** Final Project – Shopping Cart Application
**Author:** Eniya529

Paradise Nursery is an online plant shop where users can browse houseplants,
view details such as images, names, and prices, add plants to a shopping cart,
and manage the items in that cart.

## Features

- Landing page with the company name and a "Get Started" button
- About Us section describing the company
- Plants grouped into categories, each with a thumbnail, name, and price
- "Add to Cart" buttons that disable once a plant has been added
- Navbar with Home, Plants, and Cart links and a live cart item count
- Shopping cart with quantity controls, per-plant totals, and a grand total
- Delete button for each item
- "Continue Shopping" and "Checkout" (Coming Soon) buttons

## Tech Stack

- React (Vite)
- Redux Toolkit and React-Redux
- CSS

## Getting Started

    npm install
    npm run dev

Then open http://localhost:5173 in your browser.
